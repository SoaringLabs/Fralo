# Public demo media

- workbench-light.png, workbench-dark.png: the Simplified Chinese workbench in
  light and dark appearance, retained unchanged for README.zh-CN.md. Captured on
  2026-11-02 from source commit `915170af3e74901220a3761512a4f146db240283` through
  the computer-use window screenshot API. The JPEG sources were converted to PNG
  without further lossy encoding; light is 2400 × 1560 px and dark is 1200 × 780 px.
- workbench-en-light.png, workbench-en-dark.png: the English workbench in light and
  dark appearance, recaptured on 2026-11-02 using native macOS single-window capture
  for README.md. Both are 2624 × 1784 px lossless PNGs, including the complete
  1200 × 780 pt window at 2×, native system shadow, and transparent space around it.
  The window was not shared with a live capture session, so the traffic-light
  controls are visible without a purple sharing indicator. No cursor or desktop
  content is included. The UI and shadow have not been redrawn.
  The preview uses the same application source as merged commit
  `7dbff3209e2313c94e23c23acf7471ffce8a364d`, with three generated Field Notes
  inputs, an iPhone 18 Pro Max frame, and a warm 4:3 background composition.
  README.md displays the image at up to 1200 px wide, scaled to available space.
- background-1.jpg, background-2.jpg, background-3.jpg: 3:4 background compositions
  (warm preset, gradient, sage preset) rendered by FraloCore, scaled to 1000 px tall
  for the README.
- icon.png: the App icon at 256 px, exported from the compiled Fralo.icns.
- framed.png: full-resolution transparent PNG exported by the real CLI
  (`fralo render examples/01-today.png --model iphone-18-pro-max --orientation portrait`).

The input screens are generated by scripts/generate-demo.swift and licensed under MIT.
No personal screenshots, Finder dialogs, file paths, desktop content, or third-party
App screens are included. To reproduce the English captures, build and launch the
isolated Workbench Preview with `scripts/run-workbench-preview.sh`, using
`--preview-language=en`, `--preview-window=1200x780`, and
`--preview-appearance=light` or `--preview-appearance=dark`.
Import `examples/01-today.png`, `02-collection.png`, and `03-journal.png`, then choose
the background composition. Wait for the phone and all thumbnails to finish rendering.
Capture the complete window with macOS `screencapture -l <window-id>` and retain its
native shadow. Do not attach a live window-sharing session before capturing, and
keep each capture under a unique filename while checking the saved image.
