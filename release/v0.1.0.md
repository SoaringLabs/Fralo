# Fralo 0.1.0

本地批量截图套框工具的首个版本。把多张截图一次导入，统一选择 iPhone 外框、
方向和透明边距，再批量导出透明 PNG；也可以复制当前成品给其他工具。

- 原生 macOS App，支持拖入、多选、文件夹和剪贴板导入。
- 六款 iPhone Pro / Pro Max 参数化外框，支持横竖屏。
- 实时预览、放大检查、复制当前成品、单图与整批导出。
- 记住上次设置；CLI 可独立运行并复用 App 设置。
- 默认跳过同名输出，支持显式覆盖、取消和单图失败继续。
- 本地处理，无账号、无截图上传。

下载文件：Fralo-0.1.0-arm64.dmg、SHA256SUMS.txt。
校验：将两者放在同一目录，运行 shasum -a 256 -c SHA256SUMS.txt。
打开 DMG 后，将 Fralo 拖入 Applications 即可安装。
安装与首次启动说明：https://github.com/SoaringLabs/Fralo/blob/main/INSTALL.md
CLI 和说明文件保留在 App 包内。

本版 DMG 已使用 Developer ID 签名并通过 Apple 公证，公证凭证已附到安装包。
已验证环境为 Apple Silicon / macOS 27.0.1；编译目标 macOS 14，
旧系统和 Intel 尚未运行验收。外框为原创参数化绘制，不是 Apple 官方精确模板。
