# Fixed inspector illustrations

Six original, fictional device examples are generated by `scripts/generate-inspector-demos.swift` with Fralo's device renderer. They contain no user input or personal data. Phone/tablet portrait and landscape each use matching source proportions; Safari/Chrome use fixed browser examples. They explain the controls and never enter the user's export.

After `swift build --build-system native`, use the same backend’s `--show-bin-path` as the compiler's `-I` and `-L` directory, link `-lFraloCore`, and copy `Fralo_FraloCore.bundle` next to the generator executable. Run from the repository root, then commit regenerated PNGs with the generator change. Preview and Release packagers include `Fralo_FraloApp.bundle`.
