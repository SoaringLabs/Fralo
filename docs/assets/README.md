# Public demo media

- workbench-light.png, workbench-dark.png: the current Simplified Chinese workbench
  in light and dark appearance, used by README.zh-CN.md.
- workbench-en-light.png, workbench-en-dark.png: the same workbench in English, used by
  README.md. All four images were captured on 2026-11-02 from source commit
  `915170af3e74901220a3761512a4f146db240283` using the isolated Workbench Preview,
  with the three generated Field Notes inputs, an iPhone 18 Pro Max frame, and a warm
  4:3 background composition. The window is 1200 × 780 pt: light captures are
  2400 × 1560 px (2×) and dark captures are 1200 × 780 px (1×), as returned by the
  capture tool. Images contain the actual window without desktop content or system
  shadow. The README
  display width is capped at 1200 px; GitHub scales it to the available content width.
  The UI is captured as rendered, without redrawing or substituting translated text.
- background-1.jpg, background-2.jpg, background-3.jpg: 3:4 background compositions
  (warm preset, gradient, sage preset) rendered by FraloCore, scaled to 1000 px tall
  for the README.
- icon.png: the App icon at 256 px, exported from the compiled Fralo.icns.
- framed.png: full-resolution transparent PNG exported by the real CLI
  (`fralo render examples/01-today.png --model iphone-18-pro-max --orientation portrait`).

The input screens are generated by scripts/generate-demo.swift and licensed under MIT.
No personal screenshots, Finder dialogs, file paths, desktop content, or third-party
App screens are included. Workbench captures are taken from the running app through
the native computer-use window screenshot API. Its JPEG captures are converted to PNG
without further lossy encoding; no screenshot content is reconstructed. To reproduce:
use `scripts/run-workbench-preview.sh` with `--preview-language=en` or
`--preview-language=zh-Hans`, `--preview-window=1200x780`, and
`--preview-appearance=light` or `--preview-appearance=dark` to reproduce the window.
Import `examples/01-today.png`, `02-collection.png`, and `03-journal.png`, then choose the
background composition in the inspector.
