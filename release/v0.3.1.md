# Fralo 0.3.1

## English

Quick access to Fralo's official website.

### New

- Added [fralo.app](https://fralo.app) to the About window, alongside the developer's GitHub link.

### Improvements

- Updated the English and Chinese README navigation and bundled developer information with the official website.

## 简体中文

### 新增

- 在「关于 Fralo」窗口中新增 [fralo.app](https://fralo.app) 官网链接，并保留开发者 GitHub 入口。

### 改进

- 在中英文 README 导航和随包开发者信息中补充官网入口。

- 在中英文 README 導覽和隨附的開發者資訊中補充官網入口。
