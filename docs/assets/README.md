# Public demo media

- workbench.png: actual Fralo 0.1.0 App window with generated Field Notes inputs.
- workflow.gif: four actual App keyframes showing batch selection, padding changes,
  and the state after copying. Frame timing is edited for readability;
  it is not an export-speed benchmark or a continuous screen recording.
- framed.png: full-resolution transparent PNG exported by the real CLI; the GUI
  export and clipboard PNG were verified byte-identical.

The input screens are generated by scripts/generate-demo.swift and licensed under MIT.
No personal screenshots, Finder dialogs, file paths, desktop content, or third-party
App screens are included. Raw captures remain in the ignored local artifacts folder.
