# Contributing

Fralo is maintained by [Soaring Labs](https://github.com/SoaringLabs), with
[Ethan (@Peek-A-Booo)](https://github.com/Peek-A-Booo) as the current maintainer.

## Development

Use macOS with Xcode / Swift and Python 3. The package targets macOS 14.
Full App packaging compiles the layered icon with Xcode 27's actool; tests and
CLI builds do not require that icon pipeline.

Run from the repository root:

    swift test
    swift build -c release
    python3 scripts/verify_cli.py "$(swift build -c release --show-bin-path)/fralo"
    python3 scripts/check_public_source.py

The CLI checks generate ten PNG fixtures in a temporary directory and isolate
FRALO_SETTINGS_PATH. They do not require a simulator, private screenshots, network
access, or changes to your App settings.

## Changes and feedback

Keep changes focused on a concrete screenshot workflow. Include reproduction
steps, the selected model and direction, and your macOS / CPU details in bug reports.
Use generated samples or remove personal information before attaching images and logs.

For changes to rendering, check transparent bounds, original resolution, orientation,
minor cropping, and consistency between preview, export, and clipboard output.
For export changes, check existing-file handling, cancellation, failed inputs, and
protection of original screenshots.

CI checks the core and CLI. GUI interactions, icon packaging, and downloaded-App
startup need separate manual verification. An SDK deployment target is not evidence
that every older OS or CPU has been tested.

All contributions are provided under the repository's MIT license. Only contribute
assets you are entitled to distribute. Public demo inputs are generated by
scripts/generate-demo.swift; personal acceptance screenshots and design history stay
outside Git.

## DMG packaging

The DMG shows only the App and an Applications shortcut, with a saved Finder layout
and a 2x background converted from Resources/DMG/background.png. The CLI and documents remain inside the App bundle.
Python 3.10 or newer and these build-only dependencies are required:

    python3 -m venv .venv
    .venv/bin/python -m pip install -r scripts/requirements-dmg.txt
    .venv/bin/python scripts/package.py --configuration release --dmg
    .venv/bin/python scripts/verify_package.py

The installed App and CLI do not depend on Python. Convert the selected artwork with
scripts/generate-dmg-background.swift as part of packaging; no Finder automation
or manual icon placement is needed to build the DMG.

After publication, use the repository's Issues and pull requests.
The planned repository is https://github.com/SoaringLabs/Fralo; it may not exist yet.
